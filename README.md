# scope

### Students' scope

scope is a modern, all-in-one student workspace. I made this with ChatGPT. It's the first version and I will improve it alot in the next few weeks.

Track grades, manage exams, plan study sessions, stay focused, and understand your academic progress , all in one place.

scope is built with a focus on **European education systems**, with country-specific school structures, grading systems, terminology, and languages.

---

## Features

### Dashboard

Get a quick overview of your academic life.

* Current average
* Upcoming exams
* Study progress
* Focus time
* Weekly activity
* Completion statistics

### Subjects

Manage all of your subjects in one place.

* Add and remove subjects
* Track subject performance
* Connect grades and exams to subjects
* Monitor progress

### Grades

Keep track of your grades and averages.

* Weighted grades
* Subject averages
* Overall average
* Grade history
* Country-specific grading context

### Exams

Never lose track of an upcoming exam.

* Exam dates
* Subjects
* Preparation progress
* Study planning
* Upcoming exam overview

### Study Planner

Organize your study sessions and workload.

* Create study sessions
* Track completion
* Plan around exams
* View your weekly workload

### Focus Room

Stay focused while studying.

Available focus methods include:

* Pomodoro
* Deep Work
* 52/17
* Custom sessions

Focus sessions are tracked automatically so you can see how much time you actually spend studying.

### Quizzes

Create and manage study quizzes to test your knowledge and improve retention.

### Analytics

Understand your study habits and academic progress.

Track things like:

* Average grades
* Study time
* Completed sessions
* Weekly activity
* Subject performance
* Study consistency

### European Education Systems

scope adapts to the student's education system.

Supported systems include:

* Germany
* Austria
* Italy
* France
* Spain
* Netherlands
* Poland
* United Kingdom
* United States

Germany additionally supports the different **Bundesländer** and their school structures.

More systems will be added over time.

### Languages

scope supports multiple languages:

* English
* Deutsch
* Italiano
* Français
* Español
* Nederlands
* Polski

## Privacy First

scope currently works **locally in your browser**.

Your data is stored locally using browser storage.

There is currently:

* No account required
* No backend
* No database
* No tracking
* No external API required

Your data stays on your device.

You can also export and import your SCOPE data for backups.

## Getting Started

### Run locally

No installation is required.

Download or clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/scope.git
```

Open the project:

```text
scope/
├── index.html
├── css/
│   └── style.css
└── js/
    └── app.js
```

Then open:

```text
index.html
```

in your browser.

That's it.

---

## GitHub Pages

scope can also be hosted using GitHub Pages.

Go to:

**Repository → Settings → Pages**

Set:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

Your scope instance will then be available at:

```text
https://YOUR_USERNAME.github.io/scope/
```
